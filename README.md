# 🏅Meatika Desktop Editor 🏅

### Modern AI-Powered Desktop Video Editor

[![C++](https://img.shields.io/badge/C%2B%2B-20-blue.svg)]()
[![Qt](https://img.shields.io/badge/Qt-6-green.svg)]()

A modern desktop video editor built with **C++ and Qt**, combining professional editing tools with AI-powered features including **Automatic Subtitle Generation (ASR)**, **Text-to-Speech**, **Voice Cloning**, and **AI Dubbing**.
